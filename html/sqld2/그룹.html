📊 2과목 3장: GROUP BY와 HAVING

수만 건의 학생 데이터를 '학과별', '학년별'로 묶어서 통계(평균, 합계)를 내는 마법!
WHERE와 HAVING의 결정적인 차이를 완벽하게 구별해 봅시다.

1. 다중행 함수 (집계 함수)

여러 줄(행)의 데이터를 싹 다 모아서 단 1개의 통계 결과값으로 만들어주는 함수들입니다.

SUM() / AVG()

숫자 데이터의 합계와 평균을 구합니다.

(문자나 날짜 타입에는 사용할 수 없습니다.)

MAX() / MIN()

최댓값과 최솟값을 구합니다.

(숫자뿐만 아니라 날짜, 문자에도 사용 가능합니다! 문자는 사전순 배열 기준)

COUNT()

데이터의 행(Row) 개수를 셉니다.

🚨 특급 기출: COUNT(*) vs COUNT(컬럼명)

COUNT(*) : NULL이 들어있든 말든, 테이블의 모든 전체 줄(행)의 개수를 무식하게 다 셉니다.
COUNT(컬럼명) : 해당 컬럼에서 NULL인 값은 투명인간 취급하고 제외한 뒤, 데이터가 있는 건수만 셉니다!

2. GROUP BY 절: "끼리끼리 묶어라!"

특정 컬럼을 기준으로 데이터를 묶은 다음, 위에서 배운 집계 함수를 적용합니다.

-- 학과별로 학생 수와 평균 학점을 구하라!
SELECT 학과명, COUNT(*), AVG(학점)
FROM 학생
GROUP BY 학과명;

⚠️ GROUP BY 작성 시 절대 규칙 (문법 에러 주의!)

SELECT 절에 기재된 컬럼들 중에서 집계 함수(SUM, AVG 등)에 싸여있지 않은 일반 컬럼은, 무조건 모두 GROUP BY 절에 적어줘야 합니다. 안 그러면 SQL 에러가 발생합니다.

3. 100% 출제: WHERE vs HAVING

둘 다 데이터를 걸러내는(필터링) 역할을 하지만, '언제(순서)' 걸러내느냐가 완전히 다릅니다.

구분 WHERE 절 HAVING 절
역할 원본 데이터(개별 행)를 가장 먼저 걸러냄 그룹으로 묶인(통계) 결과를 마지막에 걸러냄
실행 순서 GROUP BY 이전에 실행됨 GROUP BY 이후에 실행됨
집계 함수
사용 가능?		 절대 사용 불가 ❌
(WHERE AVG(학점) > 3.0 ➔ 에러 발생)		 사용 가능 ⭕
(HAVING AVG(학점) > 3.0 ➔ 정상 작동)

💻 실전 쿼리로 이해하기

-- 1. [WHERE] : 3학년 이상인 학생들만 먼저 솎아낸 뒤,
SELECT 학과명, AVG(학점)
FROM 학생
WHERE 학년 >= 3
GROUP BY 학과명
-- 2. [HAVING] : 그렇게 묶인 학과별 평균 학점이 3.5 이상인 학과만 보여줘!
HAVING AVG(학점) >= 3.5;

🎯 이것만은 꼭 기억하세요!

  • 집계 함수(SUM, MAX 등)는 NULL인 데이터를 투명인간 취급하고 계산한다.
  • COUNT(*)는 유일하게 NULL까지 포함하여 전체 줄 수를 센다.
  • WHERE 절에는 SUM(), AVG() 같은 집계 함수를 절대로 쓸 수 없다.
  • HAVING 절은 GROUP BY 뒤에 오며, 그룹핑된 통계 결과를 걸러내는 필터다.
