🗡️ 2과목 1장: SQL 명령어 4대장과 SELECT 기초

데이터베이스에게 내리는 명령어(SQL)들을 성격에 따라 4개로 분류합니다.
명령어들의 소속을 정확히 구별하는 것이 모든 SQL 문제의 시작입니다!

1. SQL 언어의 4가지 분류 (매우 중요!)

DDL
Data Definition Language
CREATE
ALTER
DROP
RENAME
TRUNCATE
(데이터 정의어)
건물(테이블)의 뼈대를 세우고, 고치고, 부수는 명령어들입니다. 실행 즉시 DB에 영구 반영(Auto-Commit)되므로 롤백(취소)이 불가능합니다.
DML
Data Manipulation Language
SELECT
INSERT
UPDATE
DELETE
(데이터 조작어)
건물 안에 사람(데이터)을 넣고, 빼고, 조회하는 가장 많이 쓰는 명령어들입니다. 반드시 수동으로 Commit을 해줘야 반영됩니다.
DCL
Data Control Language
GRANT
REVOKE
(데이터 제어어)
DBA가 사용자에게 권한을 주거나(GRANT) 뺏는(REVOKE) 보안 관련 명령어입니다.
TCL
Transaction Control Language
COMMIT
ROLLBACK
SAVEPOINT
(트랜잭션 제어어)
DML(조작어)로 작업한 내용을 최종 승인(Commit)하거나, 에러가 났을 때 작업 전으로 취소(Rollback)시키는 생명줄입니다.

3. SELECT 구문의 6가지 뼈대 (작성 순서 vs 실행 순서)

수만 건의 데이터 중 원하는 데이터를 찾아내는 SELECT 쿼리는 작성하는 순서와, 컴퓨터(DB)가 실제로 실행하는 순서가 완전히 다릅니다.

✍️ 개발자가 쿼리를 '작성'하는 순서

  • 1 SELECT (조회할 컬럼)
  • 2 FROM (대상 테이블)
  • 3 WHERE (데이터 필터 조건)
  • 4 GROUP BY (그룹화할 컬럼)
  • 5 HAVING (그룹에 대한 조건)
  • 6 ORDER BY (정렬 기준)
➔

⚙️ DB가 쿼리를 '실행'하는 순서 (시험 출제!)

  • 1 FROM (어느 테이블에서?)
  • 2 WHERE (어떤 데이터를 뽑아서?)
  • 3 GROUP BY (어떻게 그룹을 묶고?)
  • 4 HAVING (그 그룹 중 누구를 살릴까?)
  • 5 SELECT (그중 어떤 컬럼만 보여줄까?)
  • 6 ORDER BY (마지막으로 어떻게 정렬할까?)
