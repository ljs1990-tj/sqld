🗡️ 2과목 2장: WHERE 조건절과 핵심 함수

수만 건의 데이터 중 내가 원하는 데이터만 정확하게 낚아채는 마법의 연산자들과,
까다로운 NULL 값을 처리하고 조건문(IF-THEN-ELSE)을 부여하는 단일행 함수를 마스터합니다.

1. WHERE 조건절: 다중 조건 연산자 (IN, BETWEEN, LIKE)

단순히 =, >, < 같은 비교 연산자 말고, 실무에서 가장 많이 쓰는 3가지 특수 연산자입니다.

① IN (A, B, C)

여러 개의 'OR' 조건을 하나로 깔끔하게 묶어주는 연산자입니다.

-- 학과가 컴공이거나 경영인 학생
WHERE 학과 IN ('컴공', '경영')

② BETWEEN A AND B

특정 '범위'를 지정할 때 씁니다. 중요한 점은 A와 B 값이 포함(이상/이하)된다는 것입니다.

-- 학점이 3.0 이상 ~ 4.0 이하
WHERE 학점 BETWEEN 3.0 AND 4.0

③ LIKE '패턴'

일부분만 일치해도 검색이 가능한 패턴 매칭입니다. 2가지 와일드카드를 꼭 외우세요.

  • % : 0개 이상의 모든 문자 허용
  • _ : 딱 1개의 문자만 허용

🚨 LIKE 연산자 기출 함정: ESCAPE

문제: 데이터 안에 진짜 '%' 기호나 '_' 기호가 글자로 들어있어서 검색하고 싶을 땐 어떻게 하나요?
정답: ESCAPE 키워드를 사용해서 와일드카드 기능이 아님을 선언합니다.

-- '100%' 라는 글자가 포함된 데이터 찾기
WHERE 비고 LIKE '%100@%%' ESCAPE '@'

➔ 해석: "@ 뒤에 오는 %는 패턴 기호가 아니라 진짜 % 글자 취급해라!"

2. NULL을 길들이는 함수들 (기출 0순위)

앞서 배운 NULL의 '블랙홀 법칙' 때문에, 연산 오류를 막으려면 NULL을 다른 숫자나 문자로 변환해 줘야 합니다.

함수명 (오라클 기준) 기능 설명 및 기출 포인트
NVL (컬럼, 대체값)
* SQL Server는 ISNULL		 컬럼 값이 NULL이면 ➔ '대체값' 출력
NULL이 아니면 ➔ 원래 값 그대로 출력
예: NVL(장학금, 0) ➔ 장학금이 NULL이면 0원으로 처리
NVL2 (컬럼, A, B) 컬럼 값이 NULL이 아니면 ➔ A 출력
컬럼 값이 NULL이면 ➔ B 출력
NULLIF (A, B) [가장 많이 틀리는 기출 함정!]
A와 B가 같으면 ➔ NULL을 반환
A와 B가 다르면 ➔ A (첫 번째 값)를 반환
COALESCE (A, B, C...) 괄호 안의 값들을 순서대로 보면서, 최초로 NULL이 아닌 값 하나를 만나면 바로 반환하고 종료.

3. SQL의 조건문: IF-THEN-ELSE 구현하기

프로그래밍의 조건문(IF문)을 SQL에서는 DECODE와 CASE문으로 구현합니다.

① DECODE 함수 (오라클 전용)

기준 값이 조건 값과 '정확히 일치(=)'할 때만 변환해 주는 함수입니다. (크다/작다 비교 불가)

DECODE(성별컬럼, 'M', '남자', 'F', '여자', '알수없음')

➔ 해석: 성별이 'M'이면 '남자', 'F'면 '여자', 둘 다 아니면(기본값) '알수없음' 출력

② CASE 문 (표준 SQL)

DECODE보다 훨씬 강력합니다. 일치하는 것뿐만 아니라 크다, 작다 등 다양한 조건식(>, <, BETWEEN 등)을 적용할 수 있습니다.

CASE
  WHEN 성적 >= 90 THEN 'A학점'
  WHEN 성적 >= 80 THEN 'B학점'
  ELSE 'C학점'
END AS 학점등급

💡 CASE 문 실전 암기 팁

CASE문은 반드시 END로 닫아줘야 문법 오류가 나지 않습니다. 또한 조건을 위에서부터 순서대로 검사하기 때문에 순서(로직) 구성에 주의해야 합니다.
