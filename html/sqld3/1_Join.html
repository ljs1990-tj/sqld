🧲 SQLD 2과목 심화: JOIN 완벽 이해

흩어진 테이블을 하나로 합치는 데이터베이스의 꽃!
오라클 문법과 ANSI(표준) 문법의 차이를 구별하는 것이 합격의 열쇠입니다.

1. 조인의 기본: INNER JOIN과 OUTER JOIN

조인은 교집합을 구하느냐, 아니면 한쪽 데이터를 무조건 다 살리느냐에 따라 크게 두 가지로 나뉩니다.

① INNER JOIN (내부 조인)

양쪽 테이블에 모두 데이터가 존재하는(교집합) 행만 연결하여 결과로 출력합니다. (일반적인 = 조인)

  • 가장 기본이 되는 조인입니다.
  • 조인 조건에 맞지 않는 빈 데이터는 과감히 버립니다.

② OUTER JOIN (외부 조인)

한쪽 테이블에는 데이터가 있고 반대쪽에는 없어도, 기준이 되는 테이블의 데이터는 무조건 살려서(NULL로 채워서) 출력합니다.

  • LEFT OUTER JOIN: 왼쪽 테이블 데이터 무조건 보존
  • RIGHT OUTER JOIN: 오른쪽 테이블 데이터 무조건 보존
  • FULL OUTER JOIN: 양쪽 모두 보존 (LEFT + RIGHT)

🚨 특급 기출: 오라클(+) 문법 해석하기

오라클(Oracle) 전용 외부 조인 문법은 (+) 기호를 사용합니다. 이때 (+) 기호가 붙은 쪽이 "데이터가 모자라서 억지로 NULL을 채워 넣어야 하는 쪽"입니다.

SELECT *
FROM 학생 A, 수강내역 B
WHERE A.학번 = B.학번(+);

➔ 해석: "수강내역(B)이 모자라다(+) = 학생(A) 데이터는 무조건 다 살려라!"
➔ 결론: 이것은 LEFT OUTER JOIN과 똑같은 쿼리입니다.

2. 기출 0순위: ANSI 표준 특수 조인 문법

오라클 문법인 WHERE A.키 = B.키를 대신하여, FROM 절에서 명시적으로 조인 조건을 적어주는 ANSI(표준) 문법 3가지입니다. 이 세 가지의 차이점을 묻는 문제가 매회 나옵니다.

조인 종류 작성 예시 핵심 특징 및 기출 함정
ON 조건절 SELECT A.학번, B.학과명
FROM 학생 A JOIN 학과 B
ON (A.학과코드 = B.학과코드) 		• 가장 일반적인 방법.
• 양쪽 테이블의 컬럼 이름이 달라도 조인 가능.
• 테이블 Alias(A., B.) 사용 필수.
USING 조건절 SELECT 학과코드, A.이름
FROM 학생 A JOIN 학과 B
USING (학과코드) 		• 조인하는 컬럼 이름이 반드시 같아야 함.
• 🚨 [함정] USING 절에 쓰인 컬럼 앞에는 절대 테이블 Alias(A., B.)를 붙일 수 없음! (붙이면 문법 에러)
NATURAL JOIN SELECT 학과코드, A.이름
FROM 학생 A NATURAL JOIN 학과 B 		• 이름과 데이터 타입이 똑같은 모든 컬럼을 찾아 알아서 몽땅 조인함.
• 🚨 [함정] USING과 마찬가지로, 조인된 컬럼 앞에는 Alias(A., B.) 사용 불가!

3. 기타 반드시 알아야 할 특수 조인

① CROSS JOIN (카테시안 곱)

조인 조건(WHERE 절이나 ON 절)을 아예 적지 않았을 때 발생합니다.

  • A테이블이 3줄, B테이블이 4줄이면 결과는 3 x 4 = 12줄이 뻥튀기되어 나옵니다.
  • 모든 경우의 수를 다 조합합니다.

② SELF JOIN (셀프 조인)

나 자신과 조인하는 아주 특이한 방식입니다.

  • 사원 테이블에서 '내 매니저의 이름'을 찾을 때 주로 씁니다. (사원번호 = 매니저번호)
  • 동일한 테이블을 2번 부르므로 반드시 서로 다른 테이블 Alias(별칭)를 주어(A, B) 식별해야 합니다.

💡 Non-Equi Join (비등가 조인)

조인은 무조건 같다(=) 조건으로만 묶을 수 있는 것이 아닙니다. BETWEEN A AND B, >, < 등 크기를 비교하여 범위에 속하는 값들을 묶는 것을 비등가 조인이라고 부릅니다. (예: 내 점수가 속한 학점 등급표 테이블과 조인할 때)

🎯 실전 시험장 1초 컷 핵심 요약

  • ✅ 오라클 외부 조인에서 (+) 기호가 있는 쪽이 반대쪽(OUTER)이다.
  • ✅ NATURAL JOIN과 USING 절에 명시된 공통 컬럼은 SELECT A.학과코드 처럼 별칭(A.)을 절대로 붙일 수 없다.
  • ✅ SELF JOIN은 1개의 테이블을 쓰지만, 논리적으로 구분하기 위해 반드시 2개의 Alias를 지정해야 한다.
