🧲 실전 SQL 쿼리: JOIN 완벽 분석

제공해주신 3개의 테이블(STUDENT, ENROL, SUBJECT)을 결합하여
실제 시험에서 쿼리가 어떻게 출제되고 어떤 결과가 나오는지 살펴봅니다.

1. INNER JOIN (내부 조인)

🎓 요구사항: 옥한빛 학생(20153075)이 수강한 과목명과 성적을 조회하시오.

* 해설: 학생 이름은 STUDENT에, 성적은 ENROL에, 과목명은 SUBJECT에 있습니다. 즉, 3개의 테이블을 조인해야 합니다.

[Oracle 표준 구문]

SELECT A.stu_name, C.sub_name, B.enr_grade
FROM student A, enrol B, subject C
WHERE A.stu_no = B.stu_no -- 1차 조인
  AND B.sub_no = C.sub_no -- 2차 조인
  AND A.stu_name = '옥한빛';

[ANSI 표준 구문]

SELECT A.stu_name, C.sub_name, B.enr_grade
FROM student A
JOIN enrol B ON (A.stu_no = B.stu_no)
JOIN subject C ON (B.sub_no = C.sub_no)
WHERE A.stu_name = '옥한빛';

2. OUTER JOIN (외부 조인)

🎓 요구사항: 등록된 모든 학생의 수강 내역(과목번호, 성적)을 조회하되, 수강신청을 아예 하지 않은 학생(심수정, 진현무)도 결과에 포함시키시오.

[Oracle 구문] (+) 기호 사용

SELECT A.stu_name, B.sub_no, B.enr_grade
FROM student A, enrol B
WHERE A.stu_no = B.stu_no(+);

➔ 수강내역(B)이 없어도 학생(A) 정보는 살려라!

[ANSI 구문] LEFT OUTER JOIN

SELECT A.stu_name, B.sub_no, B.enr_grade
FROM student A
LEFT OUTER JOIN enrol B
  ON (A.stu_no = B.stu_no);

3. 기출 함정: NATURAL JOIN과 USING 절

두 테이블(STUDENT, ENROL)에 공통으로 존재하는 컬럼명은 stu_no 딱 하나입니다. 이를 활용하는 ANSI 특수 문법입니다.

✅ 올바른 작성법

-- 1. USING 사용 (공통 컬럼명을 직접 명시)
SELECT stu_no, A.stu_name, B.enr_grade
FROM student A JOIN enrol B USING (stu_no);

-- 2. NATURAL JOIN 사용 (자동으로 공통 컬럼 탐색)
SELECT stu_no, A.stu_name, B.enr_grade
FROM student A NATURAL JOIN enrol B;

🚨 시험에 무조건 나오는 오답 패턴 (문법 에러)

SELECT A.stu_no, A.stu_name, B.enr_grade
FROM student A NATURAL JOIN enrol B;

[해설] NATURAL JOIN이나 USING 절로 조인된 공통 컬럼(stu_no)은 테이블 별칭(Alias)인 A. 이나 B. 를 붙여서 사용하면 무조건 SQL 에러가 발생합니다! 기출문제 보기에서 식별자(A.)가 붙어있다면 바로 오답으로 걸러내세요.
