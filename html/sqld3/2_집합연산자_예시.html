1. UNION vs UNION ALL 비교

위의 [집합 A]와 [집합 B]를 이어 붙여 보겠습니다.

결과 1: UNION ALL (단순 합집합)

-- 1학년 + 기계과
SELECT stu_name, stu_dept FROM student WHERE stu_grade = 1
UNION ALL
SELECT stu_name, stu_dept FROM student WHERE stu_dept = '기계';

3. 기출 단골: 쿼리 문법 에러 찾기

다음 쿼리들은 SQLD 시험에서 보기로 자주 등장하는 실행 불가(에러) 쿼리들입니다.

❌ 에러 원인 1: 컬럼의 개수나 타입이 다름

SELECT stu_no, stu_name FROM student   -- 컬럼 2개 (문자, 문자)
UNION
SELECT sub_no, sub_grade FROM subject    -- 컬럼 2개 (문자, 숫자)

➔ 개수는 2개로 같지만, 위쪽 두 번째 컬럼(stu_name)은 문자형인데 아래쪽 두 번째 컬럼(sub_grade)은 숫자형이라서 에러가 납니다.

❌ 에러 원인 2: ORDER BY의 위치 잘못됨

SELECT stu_name FROM student WHERE stu_grade = 1 ORDER BY stu_name
UNION ALL
SELECT stu_name FROM student WHERE stu_dept = '기계';

➔ ORDER BY는 무조건 덩어리를 다 합치고 난 가장 마지막에 딱 한 번만 적어야 합니다. 첫 번째 SELECT 문에 넣으면 에러가 납니다!
