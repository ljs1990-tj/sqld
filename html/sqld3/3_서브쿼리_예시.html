🕵️‍♂️ 실전 SQL 쿼리: 서브쿼리 완벽 분석

어느 절에 들어갔느냐에 따른 명칭(스칼라, 인라인 뷰, 중첩)과
결과 건수에 따른 연산자(단일행 vs 다중행)의 차이를 눈으로 확인합니다.

1. SELECT 절: 스칼라 서브쿼리

🎓 요구사항: 각 학생의 이름, 키, 그리고 '전체 학생의 평균 키'를 하나의 표에 나란히 출력하시오. (단, 키가 입력된 학생만 조회)

SELECT stu_name, stu_height,
  (SELECT ROUND(AVG(stu_height), 1) FROM student) AS avg_height
FROM student
WHERE stu_height IS NOT NULL;

➔ 메인 쿼리의 행(Row)마다 서브쿼리의 단일 결과(170.1)가 하나의 컬럼(칸)처럼 딱 맞춰 출력됩니다.

2. WHERE 절: 다중행 연산자 (IN)

🎓 요구사항: '컴퓨터개론(과목코드: 101)'을 수강 신청한 학생들의 이름을 조회하시오.

SELECT stu_name, stu_dept
FROM student
WHERE stu_no IN (SELECT stu_no FROM enrol WHERE sub_no = '101');

📊 쿼리 실행 흐름

Step 1 (서브쿼리 먼저 실행): 101번 과목을 수강한 학번 리스트를 뽑아냅니다.
➔ 결과: ('20131001', '20131025')

Step 2 (메인쿼리 실행): 학생 테이블에서 위 두 학번에 해당하는 학생을 찾습니다.
➔ 결과: 김종헌, 옥성우

🚨 단골 오답 패턴 (반드시 기억하세요!)

WHERE stu_no = (SELECT stu_no FROM enrol WHERE sub_no = '101');

서브쿼리의 결과가 2건('20131001', '20131025')이 나왔는데, 단일행 비교 연산자인 = 를 사용했기 때문에 즉시 ORA-01427 에러가 발생하며 쿼리가 실패합니다.

3. EXISTS를 활용한 연관 서브쿼리

🎓 요구사항: 어떤 과목이든 상관없이 '수강신청을 1건이라도 한 적이 있는' 학생들의 이름을 조회하시오.

SELECT A.stu_name
FROM student A
WHERE EXISTS
  (SELECT 1 FROM enrol B WHERE A.stu_no = B.stu_no);

💡 EXISTS의 작동 원리

메인 쿼리(학생 A)에서 학생을 한 명씩 꺼내어 서브쿼리로 던집니다. ENROL 테이블을 뒤지다가 해당 학생의 학번(A.stu_no)이 단 1줄이라도 발견되면 즉시 탐색을 멈추고 TRUE를 반환합니다. 수강 내역이 아예 없는 심수정, 진현무는 FALSE가 되어 결과에서 빠집니다.
