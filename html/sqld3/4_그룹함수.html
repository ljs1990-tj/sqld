📊 SQLD 2과목 심화: 그룹 함수 심화

단순히 그룹을 묶는 것을 넘어, '소계'와 '총합'을 한 방에 뽑아냅니다.
각 함수가 어떤 조합의 결과를 만들어내는지 완벽히 외워야 합니다.

1. 3대 확장 그룹 함수 비교 (기출 0순위)

인자로 (A, B) 두 개의 컬럼을 주었을 때, 각각 어떤 소계/총계를 만들어내는지 비교해 봅시다.

① ROLLUP N+1 개

오른쪽에서 왼쪽으로 순차적으로 묶어가며 소계와 총계를 구합니다. '순서(방향성)'가 매우 중요합니다!

GROUP BY ROLLUP(A, B)
1. (A, B)별 소계
2. (A)별 소계
3. () ➔ 전체 총계

* 컬럼이 2개면 결과 조합은 3(2+1)가지가 나옵니다. ROLLUP(B,A)로 순서를 바꾸면 결과도 바뀝니다!

② CUBE 2^N 개

결합 가능한 모든 경우의 수(다차원)에 대한 소계와 총계를 모조리 다 구합니다.

GROUP BY CUBE(A, B)
1. (A, B)별 소계
2. (A)별 소계
3. (B)별 소계 (ROLLUP엔 없음!)
4. () ➔ 전체 총계

* 컬럼이 2개면 4(2²)가지, 3개면 8(2³)가지 조합이 나옵니다. 연산량이 가장 많습니다.

③ GROUPING SETS 지정한 만큼

총계나 순차적 소계 다 필요 없고, 내가 괄호 안에 지정한 컬럼의 결과만 각각 독립적으로 구해서 더해줍니다.

GROUP BY GROUPING SETS(A, B)
1. (A)별 소계
2. (B)별 소계
(※ A,B 동시 그룹이나 전체 총계는 안 나옴!)

* 평등한 관계이므로 인자의 순서가 바뀌어도 결과는 똑같습니다.

2. 소계 빈칸 채우기: GROUPING() 함수

ROLLUP이나 CUBE를 돌려서 '총계' 줄이 만들어지면, 해당 줄의 그룹 컬럼 부분은 빈칸(NULL)으로 표시됩니다. "원래 데이터가 NULL인 것"과 "소계/총계 때문에 만들어진 가짜 NULL"을 어떻게 구별할까요?

💡 GROUPING(컬럼명) 함수의 마법

이 함수는 빈칸이 소계/총계를 위해 시스템이 만들어낸 가짜 NULL이면 숫자 1을 반환하고, 원래부터 데이터가 진짜인(또는 진짜 NULL인) 경우엔 숫자 0을 반환합니다.

💻 실전 활용 예시 (CASE 문과의 조합)

실무와 시험에서 가장 많이 쓰이는 패턴입니다. 1이 나오면 '총계'라는 글자로 바꿔치기 합니다.

SELECT
  CASE WHEN GROUPING(부서명) = 1 THEN '전체총계'
       ELSE 부서명 END AS 부서명,
  SUM(매출액)
FROM 실적테이블
GROUP BY ROLLUP(부서명);
원래 출력 (GROUPING 함수 미사용) CASE + GROUPING 함수 적용 결과
영업부 | 5000
인사부 | 3000
(NULL) | 8000		 영업부 | 5000
인사부 | 3000
전체총계 | 8000

🎯 실전 시험장 1초 컷 요약표

함수명 (A, B) 입력 시 생성되는 결과 덩어리 수 특징
ROLLUP 3개 (A,B / A / 총계) 인자 순서가 중요함 (계층적)
CUBE 4개 (A,B / A / B / 총계) 모든 경우의 수. 결과가 가장 많음
GROUPING SETS 2개 (A / B) 괄호 안에 지정한 것만. 총계(NULL) 안 나옴
