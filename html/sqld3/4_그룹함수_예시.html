📊 실전 SQL 쿼리: 그룹 함수 완벽 분석

전체 10명의 학생을 '학과별(stu_dept)', '학년별(stu_grade)'로 묶어 인원수를 셀 때,
ROLLUP, CUBE, GROUPING SETS가 만들어내는 소계와 총계의 차이를 한눈에 비교합니다.

1. 3대 확장 그룹 함수 실행 결과 비교

기본 베이스 쿼리는 모두 동일합니다. GROUP BY 뒤에 어떤 함수를 씌우느냐만 다릅니다.

① ROLLUP(학과, 학년)

SELECT stu_dept, stu_grade, COUNT(*)
FROM student
GROUP BY ROLLUP(stu_dept, stu_grade);

2. 실무/기출 단골 응용: 빈칸(NULL)에 예쁜 이름표 달아주기

ROLLUP 결과를 보면 소계/총계 자리에 NULL이 뜹니다. GROUPING 함수와 CASE 문을 활용하여 이 NULL을 '모든학과', '전체총계' 등의 문자로 바꿔치기해 보겠습니다.

SELECT
  CASE WHEN GROUPING(stu_dept) = 1 THEN '모든학과'
       ELSE stu_dept END AS 학과,
  CASE WHEN GROUPING(stu_grade) = 1 THEN '모든학년'
       ELSE TO_CHAR(stu_grade) END AS 학년,
  COUNT(*) AS 학생수
FROM student
GROUP BY ROLLUP(stu_dept, stu_grade);

💡 시험 문제 푸는 팁

GROUPING(컬럼) = 1 이라는 뜻은 "소계나 총계를 계산하기 위해 시스템이 억지로 집어넣은 가짜 NULL이니?" 라고 묻는 것입니다. (참이면 1 반환) 따라서 1일 때 '총계'라는 글자를 매핑해주면 실무에서 쓰는 완벽한 보고서 형태가 완성됩니다.
