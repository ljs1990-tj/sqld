📊 그룹 함수(ROLLUP, CUBE, GROUPING SETS) 완벽 해부

이 함수들은 결국 "어떤 기준들의 집합을 UNION ALL로 묶어주는가?"를 이해하는 것이 핵심입니다.

0. [기본] 일반 GROUP BY

가장 기본적인 그룹핑입니다. 소계나 총계 따위는 없습니다.

SELECT stu_dept, stu_grade, COUNT(*)
FROM student GROUP BY stu_dept, stu_grade;
🎯 결과 조합 (총 1가지):
① (학과 + 학년) 별 인원수

1. ROLLUP(학과, 학년) : "오른쪽에서 왼쪽으로 계단식 소계"

괄호 안에 적힌 컬럼을 오른쪽부터 하나씩 지워가며(무시하며) 그룹핑을 반복합니다.

SELECT stu_dept, stu_grade, COUNT(*)
FROM student GROUP BY ROLLUP(stu_dept, stu_grade);
STU_DEPTSTU_GRADECOUNT설명
기계12① (학과+학년) 그룹핑
기계21
기계NULL3② 학년 무시 ➔ (학과)별 소계
NULLNULL10③ 전부 무시 ➔ () 전체 총계
💡 시험 단골 문제: "위 ROLLUP 쿼리와 완전히 똑같은 결과를 내는 쿼리는?"

-- ① (학과+학년) 기준
SELECT stu_dept, stu_grade, COUNT(*) FROM student GROUP BY stu_dept, stu_grade
UNION ALL
-- ② (학과) 기준
SELECT stu_dept, NULL, COUNT(*) FROM student GROUP BY stu_dept
UNION ALL
-- ③ 전체 총계
SELECT NULL, NULL, COUNT(*) FROM student;

2. CUBE(학과, 학년) : "가능한 모든 경우의 수를 다 구해!"

계단식이 아닙니다. 입력된 컬럼들로 만들 수 있는 모든 콤비네이션(조합)을 전부 계산합니다. (데이터 분석/다차원 분석용)

SELECT stu_dept, stu_grade, COUNT(*)
FROM student GROUP BY CUBE(stu_dept, stu_grade);
STU_DEPTSTU_GRADECOUNT설명
( ROLLUP과 동일한 ①, ②, ③ 결과가 먼저 출력됨 )
NULL14④ 학과 무시 ➔ (학년)별 소계
(※ ROLLUP에는 이 결과가 없습니다!)
NULL23
🎯 CUBE는 4개의 쿼리를 UNION ALL 한 것과 같습니다. (2^2 = 4개)
① GROUP BY 학과, 학년
② GROUP BY 학과
③ GROUP BY 학년     (추가됨!)
④ 전체 총계

3. GROUPING SETS(학과, 학년) : "내가 찍어준 것만 각각 구해와"

서로 연관 지어서 소계를 묶지 않습니다. 괄호 안에 있는 항목들을 각각 독립적으로 그룹핑한 뒤 위아래로 붙여줍니다.

SELECT stu_dept, stu_grade, COUNT(*)
FROM student GROUP BY GROUPING SETS(stu_dept, stu_grade);
STU_DEPTSTU_GRADECOUNT설명
기계NULL3① (학과)별 소계
전기전자NULL3
NULL14② (학년)별 소계
NULL23

🚨 주의: (학과+학년) 전체 그룹핑도 없고, 전체 총계(10명)도 출력되지 않습니다!

🎯 GROUPING SETS는 딱 2개의 쿼리를 UNION ALL 한 것과 같습니다.

-- ① (학과) 기준
SELECT stu_dept, NULL, COUNT(*) FROM student GROUP BY stu_dept
UNION ALL
-- ② (학년) 기준
SELECT NULL, stu_grade, COUNT(*) FROM student GROUP BY stu_grade;
