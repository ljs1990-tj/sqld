🌳 SQLD 2과목 심화: 계층형 질의 & Top N 쿼리

꼬리에 꼬리를 무는 조직도 데이터를 한방에 조회하는 오라클의 꽃, 계층형 쿼리!
그리고 실행 순서의 함정을 파놓은 ROWNUM 쿼리를 파헤칩니다.

1. 계층형 질의의 핵심 구조 (Oracle)

계층형 질의(Hierarchical Query)는 자기 자신을 참조하는 테이블(예: 사원테이블에 '사원번호'와 '매니저번호'가 같이 있는 경우)에서 트리 구조를 뽑아낼 때 사용합니다.

SELECT LEVEL, 사원명, 매니저번호
FROM 사원테이블
START WITH 매니저번호 IS NULL -- 1. 뿌리(Root)를 찾는다! (보통 사장님)
CONNECT BY PRIOR 사원번호 = 매니저번호; -- 2. 뿌리와 가지를 어떻게 연결할지 정한다!
LEVEL 1 : 👑 사장 (Root)
↪ LEVEL 2 : 💼 영업부장
↪ LEVEL 3 : 🧑‍💼 영업1팀 사원
↪ LEVEL 3 : 🧑‍💼 영업2팀 사원
↪ LEVEL 2 : 💼 개발부장
↪ LEVEL 3 : 🧑‍💻 개발팀 사원
핵심 키워드 의미 (기출 필수 암기)
START WITH 트리의 시작점(Root 노드)을 지정합니다. (이 조건을 만족하는 행이 LEVEL 1이 됩니다.)
CONNECT BY 부모 노드와 자식 노드를 어떻게 연결할 것인지 규칙을 정합니다.
LEVEL (가상 컬럼) 루트 데이터면 1, 그 하위 데이터면 2, 3... 식으로 계층의 깊이를 나타냅니다.
ORDER SIBLINGS BY 전체 정렬이 아니라, 같은 레벨(형제 노드)끼리만 예쁘게 정렬할 때 사용합니다.

2. 기출 0순위: 전개 방향 맞추기

시험에서는 PRIOR 키워드의 위치를 보고 이 트리가 위에서 아래로(순방향) 가는지, 아래서 위로(역방향) 가는지 묻는 문제가 단골로 나옵니다.

⬇️ 순방향 전개 (Top-Down)

CONNECT BY PRIOR 자식컬럼(PK) = 부모컬럼(FK)

➔ 해석: "이전(PRIOR) 사원번호(나)가 매니저번호(부모)인 사람을 찾아라!" = 내 밑에 있는 부하직원들을 찾아 내려감 (사장 ➔ 사원)

⬆️ 역방향 전개 (Bottom-Up)

CONNECT BY PRIOR 부모컬럼(FK) = 자식컬럼(PK)

➔ 해석: "이전(PRIOR) 매니저번호(내 상사)가 사원번호(PK)인 사람을 찾아라!" = 나를 관리하는 상사를 찾아 올라감 (사원 ➔ 사장)

💡 암기 팁: "프.자.부.순" (PRIOR 쪽이 자식 = 부모, 이면 순방향)

3. Top N 쿼리와 ROWNUM의 치명적 함정

🎓 요구사항: STUDENT 테이블에서 키(stu_height)가 가장 큰 Top 3 학생을 조회하시오.

❌ 초보자의 실수 (실행 순서의 함정)

SELECT stu_name, stu_height
FROM student
WHERE ROWNUM <= 3   -- 여기서 아무나 3명을 먼저 짤라버림!
ORDER BY stu_height DESC;

이유: SQL의 실행 순서는 WHERE ➔ ORDER BY 입니다. 정렬도 하기 전에 ROWNUM이 먼저 작동해서 무작위로 3명을 뽑아버린 뒤에야 그 3명 안에서만 정렬을 해버립니다. (가장 키 큰 3명이 아닙니다!)

✅ 올바른 작성법 (인라인 뷰 서브쿼리 사용)

안쪽 괄호(인라인 뷰)에서 먼저 완벽하게 정렬을 끝내 놓은 가상 테이블을 만든 뒤, 바깥쪽에서 잘라야 합니다.

SELECT * FROM (         -- 2. 밖에서 ROWNUM으로 3건만 자른다.
  SELECT stu_name, stu_height
  FROM student
  WHERE stu_height IS NOT NULL
  ORDER BY stu_height DESC  -- 1. 안에서 완벽하게 정렬을 끝낸다!
)
WHERE ROWNUM <= 3;

🎯 실전 시험장 1초 컷 요약

  • ✅ START WITH 절은 데이터 필터링이 아니라, 트리의 시작 위치(Root)를 결정하는 절이다.
  • ✅ PRIOR 자식 = 부모 형태면 부모에서 자식으로 내려가는 순방향 전개다.
  • ✅ 오라클에서 정렬된 상위 N건(Top-N)을 뽑으려면 반드시 인라인 뷰 안에 ORDER BY를 먼저 써야 한다.
  • ✅ SQL Server(MSSQL)는 인라인 뷰 없이 그냥 SELECT TOP(3) 이름 FROM 학생 ORDER BY 키 로 쓴다.
