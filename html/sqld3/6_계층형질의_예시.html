1. 방향의 결정: PRIOR의 위치 (기출 0순위)

시험에서 PRIOR의 위치를 보고 트리가 위에서 아래로 가는지(순방향), 아래서 위로 가는지(역방향) 맞추는 문제가 반드시 나옵니다.

[순방향] 사장님 ➔ 사원 탐색

SELECT LEVEL, emp_name, mgr_no
FROM emp
START WITH mgr_no IS NULL -- 시작: 나사장
CONNECT BY PRIOR emp_no = mgr_no;
-- (나의 사번 = 누군가의 매니저사번)
LEVELEMP_NAME
1나사장
2  김팀장
3    이사원

[역방향] 사원 ➔ 사장님 탐색

SELECT LEVEL, emp_name, mgr_no
FROM emp
START WITH emp_name = '최사원' -- 시작: 최사원
CONNECT BY PRIOR mgr_no = emp_no;
-- (나의 매니저사번 = 누군가의 사번)
LEVELEMP_NAME
1최사원
2  박팀장
3    나사장

💡 [암기법] 프.자.부.순 : PRIOR 뒤에 자식(PK) 컬럼이 오면 '순방향'이다!

2. Top N 쿼리: ROWNUM의 치명적 함정

🎓 요구사항: STUDENT 테이블에서 키(stu_height)가 가장 큰 3명의 학생을 조회하시오.

❌ 오답 쿼리 (의도와 다르게 작동함)

SELECT stu_name, stu_height
FROM student
WHERE ROWNUM <= 3    -- 1. 무작위로 3명을 먼저 뽑음 (함정!)
ORDER BY stu_height DESC; -- 2. 뽑힌 3명 안에서 정렬함

이태연162가장 큰 학생이 아님!

✅ 정답 쿼리 (인라인 뷰 서브쿼리 사용)

SELECT *
FROM (   -- 1. 안쪽에서 '미리 완벽하게' 정렬을 끝내놓는다.
    SELECT stu_name, stu_height FROM student
    WHERE stu_height IS NOT NULL
    ORDER BY stu_height DESC
)
WHERE ROWNUM <= 3; -- 2. 정렬된 덩어리에서 상위 3개만 깔끔하게 자른다.
