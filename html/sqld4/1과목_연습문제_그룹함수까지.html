트랜잭션
Q1. 트랜잭션의 4가지 고유 특성(ACID) 중, "트랜잭션 내의 모든 연산은 반드시 데이터베이스에 모두 반영되든지, 아니면 전혀 반영되지 않아야 한다"는 특성은 무엇인가?
  • ① 원자성 (Atomicity)
  • ② 일관성 (Consistency)
  • ③ 고립성 (Isolation)
  • ④ 지속성 (Durability)
정답: ① 원자성
원자성(Atomicity)은 All or Nothing을 의미합니다. 일관성은 무결성 제약조건 만족, 고립성은 타 트랜잭션 간섭 금지, 지속성은 성공 시 영구 반영을 뜻합니다.
명령어
Q2. 다음 중 SQL 명령어의 종류가 올바르게 짝지어지지 않은 것은?
  • ① DDL - CREATE, ALTER, DROP
  • ② DML - INSERT, UPDATE, DELETE
  • ③ TCL - COMMIT, ROLLBACK, SAVEPOINT
  • ④ DCL - GRANT, RENAME, REVOKE
정답: ④
RENAME은 테이블 등의 이름을 변경하는 DDL 명령어입니다. DCL은 데이터 제어어(GRANT, REVOKE)입니다.
TCL
Q3. 트랜잭션 관리(TCL)와 자동 커밋(Auto Commit)에 대한 설명으로 가장 옳지 않은 것은? (오라클 기준)
  • ① CREATE, ALTER, DROP 등 DDL 명령어를 수행하면 내부적으로 자동 커밋이 발생한다.
  • ② DML 문장 실행 후 시스템 장애가 발생하여 비정상 종료되면 해당 트랜잭션은 자동 롤백된다.
  • ③ SAVEPOINT SV1; 설정 후 ROLLBACK TO SV1;을 실행하면 전체 트랜잭션이 취소된다.
  • ④ COMMIT을 수행하면 변경 사항이 영구적으로 DB에 저장되며, 이후에는 롤백할 수 없다.
정답: ③
ROLLBACK TO SV1; 을 실행하면 트랜잭션 전체가 취소되는 것이 아니라, 해당 세이브포인트(SV1) 이후의 작업만 취소됩니다.
명령어
Q4. 데이터를 삭제하는 명령어인 DELETE, TRUNCATE, DROP에 대한 설명으로 옳은 것은?
  • ① DELETE 명령어는 테이블 구조 자체를 삭제한다.
  • ② TRUNCATE 명령어는 DDL이므로 실행 후 ROLLBACK이 불가능하다.
  • ③ DROP 명령어는 테이블의 데이터만 지우고 디스크 저장 공간은 유지한다.
  • ④ DELETE 명령어로 데이터를 지우면 디스크 저장 공간이 즉각적으로 반환된다.
정답: ②
TRUNCATE는 DDL이라 롤백이 불가하고 공간이 즉시 반환됩니다. DELETE는 DML이라 롤백 가능, 공간 유지. DROP은 테이블 구조까지 완전히 삭제(DDL)합니다.
DML
Q5. 다음 DML 문장 중 구문상 오류가 발생하는 것은? (단, EMP 테이블의 컬럼은 EMPNO, ENAME 2개뿐이다)
  • ① INSERT INTO EMP VALUES (1000, '홍길동');
  • ② INSERT INTO EMP (EMPNO) VALUES (2000);
  • ③ UPDATE EMP SET ENAME = '이순신';
  • ④ INSERT INTO EMP (ENAME, EMPNO) VALUES (3000, '강감찬');
정답: ④
지정한 컬럼명 리스트의 순서와 VALUES 데이터의 타입이 맞아야 합니다. ENAME(문자) 자리에 3000(숫자), EMPNO(숫자) 자리에 '강감찬'(문자)가 들어가 데이터 타입 충돌로 오류가 발생합니다.
조건 및 연산
Q6. SQL의 연산자 우선순위가 높은 것부터 낮은 순서로 올바르게 나열된 것은?
  • ① 괄호( ) ➔ NOT ➔ AND ➔ OR
  • ② 괄호( ) ➔ AND ➔ NOT ➔ OR
  • ③ 괄호( ) ➔ OR ➔ AND ➔ NOT
  • ④ 괄호( ) ➔ AND ➔ OR ➔ NOT
정답: ①
논리 연산자의 우선순위는 괄호() > NOT > AND > OR 순서입니다.
NULL 특징
Q7. 데이터베이스에서 NULL의 특성에 대한 설명으로 가장 옳지 않은 것은?
  • ① NULL은 아직 정의되지 않은 값(Unknown)이거나 알 수 없는 값이다.
  • ② NULL 값을 포함한 사칙연산(예: NULL + 10)의 결과는 무조건 0이다.
  • ③ NULL 값과 특정 값을 비교 연산(=, >, <)하면 결과는 UNKNOWN(거짓과 유사)이 반환된다.
  • ④ 컬럼 값이 NULL인지 확인하려면 '컬럼명 IS NULL' 조건을 사용해야 한다.
정답: ②
NULL 값을 포함한 사칙연산의 결과는 항상 NULL입니다. (NULL + 10 = NULL)
단일행 함수
Q8. 문자형 함수 SUBSTR에 대한 설명으로 올바른 결과값을 고르시오.
SELECT SUBSTR('SQLDEVELOPER', 4, 3) FROM DUAL;
  • ① DEV
  • ② LDE
  • ③ EVE
  • ④ LDEV
정답: ① DEV
SUBSTR(문자열, 시작위치, 길이). 'SQLDEVELOPER'의 4번째 문자('D')부터 3글자를 자르므로 'DEV'가 됩니다.
LIKE 연산자
Q9. 고객 테이블에서 이름(ENAME)이 '김'으로 시작하고, 총 3글자인 고객을 찾기 위한 WHERE 절 조건으로 올바른 것은?
  • ① WHERE ENAME LIKE '김%'
  • ② WHERE ENAME LIKE '김__'
  • ③ WHERE ENAME LIKE '_김_'
  • ④ WHERE ENAME = '김__'
정답: ② WHERE ENAME LIKE '김__'
%는 0개 이상의 문자를, _(언더바)는 정확히 1개의 문자를 의미합니다. '김' 뒤에 정확히 두 글자가 와야 하므로 '김__'이 정답입니다.
NULL 관련 함수
Q10. 다음 쿼리의 실행 결과로 올바른 것은?
SELECT COALESCE(NULL, NULL, 'SQL', 'DB') FROM DUAL;
  • ① NULL
  • ② SQL
  • ③ DB
  • ④ SQLDB
정답: ② SQL
COALESCE 함수는 괄호 안에 나열된 인자들 중 첫 번째로 NULL이 아닌 값을 반환합니다. 첫 번째, 두 번째가 NULL이므로 세 번째 값인 'SQL'이 반환됩니다.
NULL 관련 함수
Q11. 다음 함수 중, 두 개의 표현식 값이 같으면 NULL을 반환하고 같지 않으면 첫 번째 표현식 값을 반환하는 함수는?
  • ① NVL
  • ② NULLIF
  • ③ NVL2
  • ④ ISNULL
정답: ② NULLIF
NULLIF(A, B): A와 B가 같으면 NULL, 다르면 A 반환. (NVL2(A, B, C): A가 NULL이 아니면 B, NULL이면 C 반환)
단일행 함수
Q12. 숫자형 함수 TRUNC(38.567, 1)의 결과값은 얼마인가?
  • ① 38.6
  • ② 38.5
  • ③ 38
  • ④ 39
정답: ② 38.5
TRUNC는 버림 함수입니다. 두 번째 인자가 1이므로 소수점 첫째 자리까지 남기고(둘째 자리에서) 버립니다. (ROUND(38.567, 1)이었다면 38.6이 됩니다)
조건제어 함수
Q13. CASE WHEN 구문에 대한 설명으로 옳지 않은 것은?
  • ① ELSE 절이 생략되고 어떠한 WHEN 조건도 만족하지 않으면 NULL을 반환한다.
  • ② WHEN 조건은 위에서부터 순차적으로 평가되며, 참인 조건을 만나면 이후 조건은 평가하지 않는다.
  • ③ SEARCHED CASE 문은 CASE WHEN 조건식 THEN 값 형태로 다양한 부등호 비교가 가능하다.
  • ④ SIMPLE CASE 문은 내부적으로 IN 연산자와 동일하게 다중 값 동시 비교를 지원한다.
정답: ④
SIMPLE CASE 문(예: CASE 컬럼명 WHEN 'A' THEN 1...)은 내부적으로 정확한 일치(=) 연산과 동일하게 동작합니다. IN과 같이 쓰이지 않습니다.
날짜 연산
Q14. 오라클(Oracle)에서 날짜형 데이터에 숫자를 더하거나 빼는 연산에 대한 설명으로 옳은 것은?
  • ① 날짜 + 숫자의 결과는 기존 날짜에서 숫자만큼의 '시간(Hour)'이 더해진다.
  • ② 날짜 - 날짜의 연산 결과는 두 날짜 사이의 '일(Day)' 수를 숫자로 반환한다.
  • ③ 날짜 데이터에 사칙연산(*, /)을 수행하여 날짜를 곱할 수 있다.
  • ④ 날짜 + 1/24 연산을 수행하면 기존 날짜에 1분이 더해진다.
정답: ②
오라클에서 날짜 연산의 기본 단위는 '일(Day)'입니다. 날짜+1은 다음 날, 날짜-날짜는 일수 차이입니다. 1/24는 1시간을 의미합니다.
형변환 함수
Q15. 데이터 타입의 묵시적(암시적) 형변환과 명시적 형변환에 대한 설명으로 옳지 않은 것은?
  • ① 데이터베이스가 내부적으로 데이터 타입을 변환하여 연산하는 것을 암시적 형변환이라 한다.
  • ② TO_CHAR, TO_DATE, CAST는 대표적인 명시적 형변환 함수이다.
  • ③ 문자열 '100'과 숫자 200을 더할 경우( '100' + 200 ), DBMS는 에러를 내지 않고 암시적 형변환을 통해 300을 계산해낸다(오라클 기준).
  • ④ 성능 최적화와 인덱스 사용을 위해서는 암시적 형변환을 적극적으로 활용하는 것이 바람직하다.
정답: ④
조건절에서 암시적 형변환이 발생하면 인덱스를 타지 못해 풀 테이블 스캔(Full Table Scan)이 발생할 수 있습니다. 성능과 명확성을 위해 명시적 형변환 함수를 사용하는 것이 바람직합니다.
GROUP BY
Q16. GROUP BY 및 HAVING 절에 대한 설명으로 가장 옳지 않은 것은?
  • ① GROUP BY 절에 명시되지 않은 일반 컬럼은 SELECT 절에 단독으로 올 수 없다.
  • ② WHERE 절은 GROUP BY에 의한 그룹화가 수행되기 전에 필터링을 수행한다.
  • ③ HAVING 절은 GROUP BY 연산 후에 수행되며, 집계 함수를 조건으로 사용할 수 있다.
  • ④ HAVING 절은 반드시 GROUP BY 절 뒤에만 위치해야 하며 순서를 바꿀 수 없다.
정답: ④
문법적으로 HAVING 절은 GROUP BY 절 앞이나 뒤 어디에 위치하든 논리적 결과는 동일하며 오류가 발생하지 않습니다. (다만 가독성을 위해 보통 뒤에 작성합니다.)
그룹함수 (집계)
Q17. 집계 함수(Aggregate Function)와 NULL 값 처리에 대한 설명으로 올바른 것은?
  • ① SUM(컬럼) 수행 시 컬럼 내에 NULL 값이 하나라도 있으면 연산 결과는 무조건 NULL이다.
  • ② AVG(컬럼)은 NULL 값을 제외하고 모수(분모)를 계산하여 평균을 구한다.
  • ③ COUNT(*)는 NULL 값이 포함된 행(Row)은 카운트에서 제외한다.
  • ④ COUNT(컬럼)은 NULL 값을 포함하여 해당 컬럼의 모든 행 수를 반환한다.
정답: ②
집계 함수(SUM, AVG, MAX, MIN, COUNT(컬럼))는 모두 내부적으로 NULL을 무시하고 연산합니다. 단, COUNT(*)는 행 자체의 수를 세므로 NULL 데이터도 포함하여 카운트합니다.
수행 순서
Q18. SELECT 쿼리문의 논리적 수행 순서로 올바른 것은?
  • ① FROM ➔ WHERE ➔ GROUP BY ➔ HAVING ➔ SELECT ➔ ORDER BY
  • ② SELECT ➔ FROM ➔ WHERE ➔ GROUP BY ➔ HAVING ➔ ORDER BY
  • ③ FROM ➔ WHERE ➔ HAVING ➔ GROUP BY ➔ SELECT ➔ ORDER BY
  • ④ FROM ➔ SELECT ➔ WHERE ➔ GROUP BY ➔ HAVING ➔ ORDER BY
정답: ①
수행 순서는 FROM(테이블 확인) -> WHERE(행 필터) -> GROUP BY(그룹화) -> HAVING(그룹 필터) -> SELECT(컬럼 추출) -> ORDER BY(정렬) 순입니다.
그룹함수
Q19. EMP 테이블의 급여(SAL) 데이터가 [100, 200, 300, NULL, NULL] 일 때, SELECT SUM(SAL), COUNT(SAL), COUNT(*) FROM EMP; 의 결과로 옳은 것은?
  • ① 600, 3, 3
  • ② 600, 5, 5
  • ③ 600, 3, 5
  • ④ NULL, 3, 5
정답: ③ 600, 3, 5
SUM(SAL)은 NULL 무시하고 합계 600. COUNT(SAL)은 NULL 무시하고 데이터 개수 3. COUNT(*)는 전체 행의 개수이므로 5입니다.
GROUP BY
Q20. 다중 컬럼에 대한 GROUP BY 연산에 대한 설명으로 옳은 것은?
  • ① GROUP BY A, B를 수행하면 A 컬럼과 B 컬럼이 각각 독립적으로 그룹화된다.
  • ② GROUP BY 절에는 반드시 SELECT 절에 명시된 모든 집계 함수를 포함하여 나열해야 한다.
  • ③ GROUP BY DEPTNO, JOB을 수행하면, 두 컬럼 값의 조합이 동일한 행들이 하나의 그룹으로 묶인다.
  • ④ GROUP BY 절에는 컬럼의 ALIAS(별칭)를 반드시 사용해야 한다.
정답: ③
다중 컬럼 GROUP BY는 콤마로 연결된 컬럼들의 '조합(Combination)'을 기준으로 데이터를 묶습니다.
JOIN 종류
Q21. 조인(JOIN)에 대한 설명으로 가장 옳지 않은 것은?
  • ① EQUI JOIN(등가 조인)은 두 테이블 간의 일치하는 조건( '=' 연산자 )을 사용하여 조인한다.
  • ② NON-EQUI JOIN(비등가 조인)은 BETWEEN, >, < 등의 연산자를 사용하여 조인하는 방식이다.
  • ③ N개의 테이블을 모두 조인하기 위해서는 최소 N-1개의 조인 조건이 필요하다.
  • ④ CROSS JOIN은 조인 조건이 생략되었을 때 발생하며, 결과는 두 테이블 행의 덧셈(M + N)이 된다.
정답: ④
CROSS JOIN(카테시안 곱)의 결과 행 수는 두 테이블 행의 덧셈이 아니라 **곱셈(M * N)**입니다.
OUTER JOIN
Q22. A 테이블은 5건, B 테이블은 3건의 데이터가 있다. 두 테이블을 A 테이블을 기준으로 LEFT OUTER JOIN 하였을 때, 출력될 수 있는 결과 행(Row)의 최소 건수는? (단, B 테이블의 조인 키는 유일하다)
  • ① 3건
  • ② 5건
  • ③ 8건
  • ④ 15건
정답: ② 5건
LEFT OUTER JOIN은 기준이 되는 왼쪽(A) 테이블의 데이터가 매칭 여부와 상관없이 무조건 모두 보존되어 출력됩니다. 따라서 최소 A 테이블의 건수인 5건은 무조건 출력됩니다.
표준 JOIN
Q23. ANSI 표준 JOIN 문법 중 NATURAL JOIN에 대한 설명으로 옳은 것은?
  • ① 두 테이블 간에 데이터 타입과 이름이 같은 모든 컬럼을 기준으로 자동으로 EQUI JOIN을 수행한다.
  • ② JOIN 조건에 사용되는 컬럼은 SELECT 절에서 테이블 ALIAS(별칭)를 접두사로 사용해야만 한다. (예: A.DEPTNO)
  • ③ ON 절을 함께 사용하여 조인 조건을 추가적으로 명시해야 한다.
  • ④ 두 테이블의 컬럼 이름이 달라도 데이터 타입만 같으면 자동으로 조인된다.
정답: ①
NATURAL JOIN이나 USING 절에 사용된 조인 컬럼은 식별자를 가지지 않으므로, SELECT 절이나 WHERE 절에서 **테이블 ALIAS(별칭)나 테이블명을 접두사로 사용할 수 없습니다** (②번 오답).
JOIN 조건
Q24. ANSI 표준 JOIN 구문에서 USING 절에 대한 설명으로 올바른 것은?
  • ① USING 절은 두 테이블의 조인 컬럼 이름이 다를 때 유용하게 사용된다.
  • ② USING(컬럼명) 안에 명시된 조인 컬럼은 SELECT 절에서 테이블 ALIAS 지정 시 구문 오류가 발생한다.
  • ③ USING 절과 NATURAL JOIN은 하나의 SQL 문장 내에서 동시에 사용될 수 있다.
  • ④ USING 절에는 조인 조건뿐만 아니라 일반적인 필터 조건(예: USING(A.DEPTNO = 10))도 기술할 수 있다.
정답: ②
NATURAL JOIN과 마찬가지로 USING 절에 쓰인 조인 키 컬럼은 테이블 별칭(ALIAS)을 지정할 수 없습니다. (예: SELECT A.DEPTNO (X) -> SELECT DEPTNO (O)) 이름이 다를 때는 ON 절을 씁니다.
JOIN 결과
Q25. [A 테이블: 4행], [B 테이블: 5행], [C 테이블: 3행]을 아무런 조건 없이 CROSS JOIN 하였을 때, 결과 집합의 총 행(Row) 수는?
  • ① 12행
  • ② 20행
  • ③ 60행
  • ④ 에러 발생
정답: ③ 60행
카테시안 곱(CROSS JOIN)의 결과는 각 테이블 행의 곱연산입니다. 4 × 5 × 3 = 60입니다.
표준 JOIN
Q26. 다음 구문을 동일한 결과를 내는 ANSI 표준 SQL 구문으로 바르게 변경한 것은?
SELECT E.ENAME, D.DNAME FROM EMP E, DEPT D WHERE E.DEPTNO = D.DEPTNO;
  • ① SELECT E.ENAME, D.DNAME FROM EMP E CROSS JOIN DEPT D;
  • ② SELECT E.ENAME, D.DNAME FROM EMP E LEFT OUTER JOIN DEPT D ON E.DEPTNO = D.DEPTNO;
  • ③ SELECT E.ENAME, D.DNAME FROM EMP E INNER JOIN DEPT D ON E.DEPTNO = D.DEPTNO;
  • ④ SELECT E.ENAME, D.DNAME FROM EMP E JOIN DEPT D WHERE E.DEPTNO = D.DEPTNO;
정답: ③
오라클 구문의 쉼표(,) 조인은 ANSI 표준의 INNER JOIN과 동일하며, WHERE 절의 조인 조건은 ON 절로 변경됩니다.
다중 조인
Q27. 세 개 이상의 테이블을 조인할 때 내부적인 처리 방식으로 가장 올바른 것은?
  • ① 3개의 테이블이 메모리 상에서 동시에 조인된다.
  • ② 먼저 2개의 테이블이 조인되어 중간 결과를 만들고, 그 중간 결과와 나머지 1개 테이블이 조인된다.
  • ③ WHERE 절에 기술된 순서와는 무관하게 테이블 크기가 큰 순서대로 먼저 조인된다.
  • ④ 다중 조인은 시스템에 과부하를 주므로 서브쿼리로 분리해야만 실행된다.
정답: ②
RDBMS에서 조인은 무조건 **2개의 테이블 단위**로만 수행됩니다. 3개 이상일 경우 앞의 조인 결과 집합이 다음 테이블과 다시 조인되는 방식으로 연쇄 수행됩니다.
집합연산자
Q28. 다음 중 집합 연산자(Set Operator)에 대한 설명으로 옳지 않은 것은?
  • ① 두 SELECT 문의 결과를 결합하기 위해서는 조회되는 컬럼의 개수와 데이터 타입이 상호 호환되어야 한다.
  • ② UNION 연산자는 중복된 행을 하나로 합치고, 결과를 기본적으로 정렬(Sort)하여 출력한다.
  • ③ UNION ALL 연산자는 중복된 행을 제거하지 않고 그대로 병합하며, 정렬을 수행하지 않아 UNION보다 빠르다.
  • ④ ORDER BY 절은 두 SELECT 문 각각에 개별적으로 기술하여 집합 별로 정렬할 수 있다.
정답: ④
집합 연산자를 사용할 때, ORDER BY 절은 **전체 SQL 문장의 맨 마지막에 단 한 번만** 기술할 수 있습니다.
집합연산자
Q29. 두 집합에서 공통으로 존재하는 데이터(교집합)만 추출하며 중복을 제거하는 집합 연산자는 무엇인가?
  • ① UNION
  • ② UNION ALL
  • ③ INTERSECT
  • ④ MINUS (또는 EXCEPT)
정답: ③ INTERSECT
교집합은 INTERSECT입니다. MINUS(EXCEPT)는 차집합입니다.
집합연산자
Q30. A 집합에는 {1, 2, 2, 3}의 데이터가 있고, B 집합에는 {2, 3, 4}의 데이터가 있다. SELECT * FROM A MINUS SELECT * FROM B; 의 결과로 도출되는 데이터 집합은?
  • ① {1}
  • ② {1, 2}
  • ③ {4}
  • ④ {1, 4}
정답: ① {1}
MINUS는 A 집합에서 B 집합과 겹치는 부분(2, 3)을 모두 뺀 차집합을 구합니다. 집합 연산이므로 중복된 2도 완전히 제거되어 {1}만 남습니다.
집합연산자 제약
Q31. 집합 연산자를 사용할 때 주의사항으로 옳은 것은?
  • ① 두 번째 쿼리의 컬럼 이름은 첫 번째 쿼리의 컬럼 이름과 동일해야만 한다.
  • ② 데이터 타입이 다르더라도 RDBMS가 암시적 형변환을 통해 자동으로 집합 연산을 수행해 준다.
  • ③ 최종 결과 집합의 컬럼명은 항상 첫 번째 SELECT 문의 컬럼명을 따른다.
  • ④ 결과 컬럼 수가 다를 경우 부족한 컬럼은 자동으로 NULL로 채워진다.
정답: ③
집합 연산의 결과 헤더(컬럼명)는 무조건 첫 번째 SELECT 문에 지정된 컬럼명(또는 ALIAS)을 따릅니다. 컬럼의 개수와 데이터 타입(호환 가능)은 반드시 일치해야 오류가 나지 않습니다.
서브쿼리 연산자
Q32. 반환되는 결과가 2건 이상인 다중행(Multi-Row) 서브쿼리에 사용할 수 있는 연산자가 **아닌** 것은?
  • ① IN
  • ② ANY (SOME)
  • ③ = (단일행 동등 연산자)
  • ④ ALL
정답: ③ =
=, <, >, <= 등의 연산자는 단 1건의 결과만 반환하는 단일행 서브쿼리에만 사용할 수 있습니다. 서브쿼리 결과가 다중행일 때 '='를 쓰면 ORA-01427 에러가 발생합니다.
서브쿼리 분류
Q33. 다음 서브쿼리의 종류 중 그 명칭과 위치가 올바르게 짝지어진 것은?
  • ① 스칼라 서브쿼리 (Scalar Subquery) - FROM 절
  • ② 인라인 뷰 (Inline View) - SELECT 절
  • ③ 스칼라 서브쿼리 (Scalar Subquery) - SELECT 절
  • ④ 다중행 서브쿼리 (Multi-Row Subquery) - ORDER BY 절
정답: ③ 스칼라 서브쿼리 - SELECT 절
SELECT 절에 오는 것은 스칼라 서브쿼리(1행 1열 반환), FROM 절에 오는 것은 임시 테이블 역할을 하는 인라인 뷰(Inline View)입니다.
EXISTS 연산자
Q34. 다중행 연산자인 EXISTS 에 대한 설명으로 올바른 것은?
  • ① 서브쿼리의 결과가 정확히 1건일 때만 TRUE를 반환한다.
  • ② 서브쿼리의 결과 집합 중에 만족하는 데이터가 최소 1건이라도 존재하면 TRUE를 반환한다.
  • ③ 메인쿼리의 값과 서브쿼리의 반환된 값들을 직접 비교(예: > EXISTS)하여 큰 값을 추출한다.
  • ④ 서브쿼리 내에서 집계 함수와 함께 쓰여 그룹의 존재 여부를 판단한다.
정답: ②
EXISTS 연산자는 조건에 맞는 결과 행이 단 1건이라도 존재하면 즉시 검색을 멈추고 TRUE를 반환하는 특성을 가집니다. 성능 향상을 위해 연관 서브쿼리와 함께 자주 쓰입니다.
연관 서브쿼리
Q35. 서브쿼리 내에 메인쿼리의 컬럼이 사용된 서브쿼리를 무엇이라 부르는가? (주로 메인쿼리의 각 행마다 서브쿼리가 반복 수행됨)
  • ① 비연관 서브쿼리 (Uncorrelated Subquery)
  • ② 연관 서브쿼리 (Correlated Subquery)
  • ③ 다중컬럼 서브쿼리 (Multi-Column Subquery)
  • ④ 인라인 뷰 (Inline View)
정답: ② 연관 서브쿼리
메인쿼리의 컬럼을 서브쿼리 조건에 가져다 쓰는 것을 연관 서브쿼리라고 합니다. 반대로 메인쿼리 컬럼을 쓰지 않고 자체적으로 실행 가능한 서브쿼리는 비연관 서브쿼리입니다.
스칼라 서브쿼리
Q36. SELECT 절에 작성되는 스칼라 서브쿼리(Scalar Subquery)가 정상적으로 수행되기 위해 반드시 만족해야 하는 조건은 무엇인가?
  • ① 반환되는 결과가 반드시 단 1건의 행과 1개의 컬럼(단일 값)이어야 한다.
  • ② 반환되는 결과 행의 수는 제한이 없으나, 컬럼은 반드시 1개여야 한다.
  • ③ 외부 메인쿼리의 테이블과 동일한 테이블을 조회해야만 한다.
  • ④ GROUP BY 구문을 반드시 포함해야 한다.
정답: ①
스칼라 서브쿼리는 마치 하나의 '함수'처럼 단 하나의 값만을 반환해야 합니다. 결과가 2건 이상 나오거나 2개 이상의 컬럼을 SELECT하면 에러가 발생합니다.
ROLLUP
Q37. GROUP BY ROLLUP(A, B) 를 실행했을 때, 결과로 산출되는 집계 레벨(조합)로 알맞은 것은?
  • ① (A, B) 집계만 수행
  • ② (A) 집계, (B) 집계, () 전체 합계
  • ③ (A, B) 집계, (A) 소계, () 전체 합계
  • ④ (A, B) 집계, (A) 소계, (B) 소계, () 전체 합계
정답: ③ (A, B), (A), ()
ROLLUP은 나열된 컬럼에 대해 계층적(우측에서 좌측으로)으로 소계를 구합니다. 컬럼이 2개면 n+1 인 3가지 레벨의 집계가 생성됩니다.
CUBE
Q38. GROUP BY CUBE(A, B) 를 실행했을 때 산출되는 집계 조합으로 알맞은 것은? (다차원 소계)
  • ① (A, B), (A), ()
  • ② (A), (B)
  • ③ (A, B), (B), ()
  • ④ (A, B), (A), (B), ()
정답: ④ (A, B), (A), (B), ()
CUBE는 나열된 컬럼들의 가능한 '모든 조합'에 대한 집계를 수행합니다. 컬럼이 2개면 2^2 = 4가지 레벨의 집계가 나옵니다.
GROUPING SETS
Q39. 평면적인 집계가 필요할 때 사용하며, 사용자가 명시한 개별 집계 조합들에 대해서만 결과를 출력하는 함수는? (예: A별 소계와 B별 소계만 따로 원할 때)
  • ① ROLLUP(A, B)
  • ② CUBE(A, B)
  • ③ GROUPING SETS(A, B)
  • ④ GROUP BY (A, B)
정답: ③ GROUPING SETS
GROUPING SETS(A, B)는 (A) 기준 집계와 (B) 기준 집계만 딱 잘라서 산출하며 전체 합계()나 (A, B) 조합은 자동으로 내지 않습니다.
GROUPING 함수
Q40. ROLLUP이나 CUBE 연산 시 발생하는 NULL 값(소계/합계를 위해 나타나는 빈칸)과, 실제 데이터가 NULL인 값을 구분하기 위해 제공되는 함수는?
  • ① NVL
  • ② GROUPING
  • ③ NULLIF
  • ④ COALESCE
정답: ② GROUPING
GROUPING(컬럼) 함수는 해당 컬럼이 ROLLUP/CUBE 연산에 의해 집계되어 소계로 도출된 NULL이면 '1'을, 실제 데이터 값이어서 출력된 거면 '0'을 반환하여 둘을 구분해줍니다.
총점: 0 / 100점
