🎯 SQLD 2과목 실전 모의고사 (Set 2)

함수, GROUP BY, 표준 JOIN, 서브쿼리, 윈도우 함수 등 2과목 핵심 30제입니다.
문제를 모두 풀고 하단의 채점 버튼을 누르면 점수와 해설이 공개됩니다!

Q01. 다음 중 테이블의 데이터를 삭제하는 명령어에 대한 설명으로 가장 적절하지 않은 것은?
  • ① DELETE 문은 로그를 남기며 롤백(ROLLBACK)이 가능하다.
  • ② TRUNCATE TABLE 문은 테이블의 구조까지 완전히 삭제한다.
  • ③ DROP TABLE 문은 테이블 자체를 삭제하며 복구할 수 없다. (Auto Commit)
  • ④ TRUNCATE TABLE은 DELETE보다 시스템 부하가 적고 속도가 빠르다.
해설
TRUNCATE TABLE은 테이블의 '데이터'만 모두 삭제하고 저장 공간을 초기화할 뿐, 테이블의 구조(스키마)는 그대로 유지합니다. 테이블 구조까지 삭제하는 것은 DROP TABLE입니다.
Q02. 트랜잭션의 4가지 특징(ACID) 중, 트랜잭션이 성공적으로 완료되면 그 결과는 시스템에 영구적으로 반영되어야 한다는 성질은?
  • ① 원자성 (Atomicity)
  • ② 일관성 (Consistency)
  • ③ 고립성 (Isolation)
  • ④ 지속성 (Durability)
해설
영구적 반영은 '지속성(Durability)'입니다. 원자성(All or Nothing), 일관성(모순 없음), 고립성(다른 트랜잭션 간섭 불가)도 시험 단골 출제 개념입니다.
Q03. 데이터 무결성을 보장하기 위한 제약조건 중, 기본키(Primary Key)에 대한 설명으로 틀린 것은?
  • ① 하나의 테이블에는 단 하나의 기본키만 설정할 수 있다.
  • ② 기본키는 UNIQUE 제약조건과 NOT NULL 제약조건의 결합이다.
  • ③ 기본키를 구성하는 컬럼이 여러 개일 수 있다. (복합키)
  • ④ 기본키 값으로는 NULL이 허용되나 중복은 허용되지 않는다.
해설
기본키(PK)는 식별자이므로 절대 NULL 값을 가질 수 없습니다. (NOT NULL + UNIQUE)
Q04. 다음 SELECT 문의 논리적 수행 순서로 올바른 것은?
SELECT - FROM - WHERE - GROUP BY - HAVING - ORDER BY
  • ① FROM ➔ WHERE ➔ GROUP BY ➔ HAVING ➔ SELECT ➔ ORDER BY
  • ② FROM ➔ WHERE ➔ SELECT ➔ GROUP BY ➔ HAVING ➔ ORDER BY
  • ③ SELECT ➔ FROM ➔ WHERE ➔ GROUP BY ➔ HAVING ➔ ORDER BY
  • ④ FROM ➔ GROUP BY ➔ WHERE ➔ HAVING ➔ SELECT ➔ ORDER BY
해설
[발췌(FROM) ➔ 필터(WHERE) ➔ 그룹핑(GROUP BY) ➔ 그룹필터(HAVING) ➔ 출력(SELECT) ➔ 정렬(ORDER BY)] 순서입니다. 이 순서를 알아야 SELECT 절에서 만든 ALIAS(별칭)를 WHERE 절에서 쓸 수 없는 이유를 이해할 수 있습니다.
Q05. 다음 연산의 결과 중 NULL이 반환되지 않는 것은? (단, Oracle 기준)
  • ① SELECT 100 + NULL FROM DUAL;
  • ② SELECT 'SQL' || NULL FROM DUAL;
  • ③ SELECT GREATEST(10, 20, NULL) FROM DUAL;
  • ④ SELECT 100 * NULL FROM DUAL;
해설
오라클에서 문자열 연결 연산자(||)에 NULL이 들어가면 빈 문자열로 취급되어 원래 문자열인 'SQL'이 반환됩니다. 숫자 연산(+, -, *, /)에 NULL이 포함되면 결과는 항상 NULL입니다.
Q06. 주어진 두 값이 같으면 NULL을 반환하고, 다르면 첫 번째 값을 반환하는 함수는?
  • ① NVL(expr1, expr2)
  • ② COALESCE(expr1, expr2)
  • ③ NULLIF(expr1, expr2)
  • ④ NVL2(expr1, expr2, expr3)
해설
NULLIF(A, B) 함수는 A와 B가 같으면 NULL, 다르면 A를 반환합니다.
Q07. SELECT COALESCE(NULL, NULL, 'C', 'D') FROM DUAL; 의 결과는?
  • ① NULL
  • ② C
  • ③ D
  • ④ 에러 발생
해설
COALESCE 함수는 괄호 안의 인자들을 순서대로 검사하여 최초로 NULL이 아닌 값을 반환합니다.
Q08. 다음 중 ELSE 절이 생략된 CASE WHEN 구문에서, 일치하는 조건이 없을 때 반환되는 값은?
  • ① 0
  • ② FALSE
  • ③ 에러 발생
  • ④ NULL
해설
CASE 문에서 ELSE를 생략하고 조건에 맞는 값이 없으면 기본적으로 NULL을 반환합니다.
Q09. 테이블 T1의 COL1에 데이터 [10, 20, NULL, 30]이 들어있을 때, SELECT AVG(COL1) FROM T1; 의 결과는?
  • ① 15
  • ② 20
  • ③ NULL
  • ④ 60
해설
집계 함수(SUM, AVG, MAX, MIN)는 NULL 값을 제외하고 연산합니다. 따라서 (10+20+30) / 3건 = 20이 반환됩니다. (분모가 4가 아님에 주의!)
Q10. COUNT(*)와 COUNT(컬럼명)의 차이점으로 올바른 것은?
  • ① COUNT(*)는 NULL을 포함한 테이블의 전체 행(Row) 수를 반환한다.
  • ② COUNT(컬럼명)은 NULL을 포함하여 해당 컬럼의 행 수를 반환한다.
  • ③ 두 함수의 결과는 항상 동일하다.
  • ④ COUNT(*)는 집계 함수가 아니며, GROUP BY에 쓸 수 없다.
해설
COUNT(*)는 전체 행을 세므로 NULL인 행도 1로 카운트합니다. 반면 COUNT(컬럼명)은 해당 컬럼 값이 NULL인 행은 카운트에서 제외합니다.
Q11. SELECT SUBSTR('SQL_DEVELOPER', 5, 3) FROM DUAL; 의 결과는?
  • ① SQL
  • ② DEV
  • ③ VEL
  • ④ ELO
해설
5번째 문자('D')부터 시작하여 3글자를 자르므로 'DEV'가 출력됩니다. (인덱스는 1부터 시작합니다)
Q12. SELECT ROUND(345.678, 1) FROM DUAL; 의 결과는?
  • ① 345.6
  • ② 345.7
  • ③ 346
  • ④ 340
해설
소수점 첫째 자리까지 표시하라는 뜻이므로, 둘째 자리(7)에서 반올림하여 345.7이 됩니다.
Q13. 오라클(Oracle) 환경에서 현재 날짜와 시스템 시간을 반환하는 키워드는?
  • ① GETDATE()
  • ② NOW()
  • ③ SYSDATE
  • ④ CURRENT_TIME
해설
오라클은 SYSDATE, SQL Server는 GETDATE()를 사용합니다.
Q14. GROUP BY 절에 대한 설명으로 틀린 것은?
  • ① 그룹핑 기준이 되는 컬럼 외에 다른 일반 컬럼을 SELECT 절에 단독으로 나열할 수 없다.
  • ② WHERE 절에서 그룹 함수(SUM, COUNT 등)를 사용하여 필터링할 수 없다.
  • ③ ALIAS(별칭)를 사용하여 그룹화 컬럼을 지정할 수 있다.
  • ④ 결과 데이터를 필터링하기 위해 HAVING 절을 함께 사용할 수 있다.
해설
GROUP BY 절이 SELECT 절보다 먼저 실행되므로, SELECT 절에서 정의한 별칭(ALIAS)을 GROUP BY 절에서 사용할 수 없습니다. (단, ORDER BY에서는 사용 가능)
Q15. 오라클(Oracle) 기준으로 오름차순(ASC) 정렬을 수행할 때, NULL 값의 위치는 어디인가?
  • ① 무조건 가장 먼저 출력된다. (가장 작은 값 취급)
  • ② 무조건 가장 나중에 출력된다. (가장 큰 값 취급)
  • ③ 정렬 기준 컬럼의 데이터 타입에 따라 다르다.
  • ④ 에러가 발생하여 출력되지 않는다.
해설
오라클에서 NULL은 '무한히 큰 값'으로 취급되어 오름차순(ASC) 시 맨 마지막에 출력됩니다. 반대로 SQL Server는 NULL을 최소값으로 취급하여 맨 처음에 출력합니다.
Q16. ANSI 표준 SQL에서 두 테이블 간 조인 조건 컬럼명이 동일할 때, ON 절 대신 간단하게 사용할 수 있는 키워드는?
  • ① CROSS JOIN
  • ② WHERE
  • ③ USING
  • ④ CONNECT BY
해설
조인하려는 두 테이블의 조인 컬럼 이름이 같다면 ON A.DEPTNO = B.DEPTNO 대신 USING (DEPTNO) 로 간단하게 쓸 수 있습니다.
Q17. 테이블 A(기준)에 5건, 테이블 B에 3건의 데이터가 있다. A의 모든 데이터는 출력해야 하며, B에 매칭되는 값이 없으면 NULL로 출력하는 조인 방식은?
  • ① INNER JOIN
  • ② LEFT OUTER JOIN
  • ③ RIGHT OUTER JOIN
  • ④ CROSS JOIN
해설
기준이 되는 왼쪽(A)의 데이터를 모두 유지하는 것은 LEFT OUTER JOIN 입니다.
Q18. 테이블 A의 행 수가 4건, 테이블 B의 행 수가 3건일 때 두 테이블을 CROSS JOIN한 결과 집합의 총 행(Row) 수는?
  • ① 3건
  • ② 4건
  • ③ 7건
  • ④ 12건
해설
CROSS JOIN(카티시안 곱)은 조인 조건이 없을 때 발생하며, 두 테이블의 행 수를 곱한(M × N) 개수만큼 데이터가 생성됩니다. (4 * 3 = 12)
Q19. NATURAL JOIN에 대한 설명으로 가장 적절한 것은?
  • ① 두 테이블 간에 이름과 데이터 타입이 같은 '모든' 컬럼을 기준으로 자동으로 조인된다.
  • ② 명시적으로 ON 절을 반드시 작성해야 한다.
  • ③ 조인 컬럼에 테이블 식별자(ALIAS)를 붙일 수 있다. (예: SELECT A.DEPTNO)
  • ④ 이름이 같은 컬럼이 없으면 에러가 발생한다.
해설
NATURAL JOIN은 이름과 타입이 같은 모든 컬럼을 찾아 자동으로 INNER JOIN 합니다. 또한, 자동으로 기준이 된 조인 컬럼 앞에는 테이블 별칭(Alias)을 붙일 수 없습니다.
Q20. 다음 중 '인라인 뷰(Inline View)'가 위치하는 SQL 절은 어디인가?
  • ① SELECT 절
  • ② FROM 절
  • ③ WHERE 절
  • ④ HAVING 절
해설
FROM 절에 위치하는 서브쿼리를 '인라인 뷰'라고 하며, 동적으로 생성되는 일회성 가상 테이블 역할을 합니다. (SELECT 절에 오면 '스칼라 서브쿼리'입니다.)
Q21. 서브쿼리의 결과가 2건 이상 반환될 때 사용할 수 없는 연산자는?
  • ① IN
  • ② ANY
  • ③ =
  • ④ EXISTS
해설
= 연산자는 단일행(Single Row) 연산자이므로, 서브쿼리의 결과가 2건 이상 나올 때 사용하면 에러(다중행 리턴 오류)가 발생합니다.
Q22. 메인 쿼리의 컬럼이 서브쿼리 내에 사용되어, 메인 쿼리의 각 행마다 서브쿼리가 반복해서 실행되는 구조의 쿼리를 무엇이라 하는가?
  • ① 스칼라 서브쿼리
  • ② 인라인 뷰
  • ③ 상관(연관) 서브쿼리
  • ④ 다중 컬럼 서브쿼리
해설
메인 쿼리와 조인 조건을 맺고 메인 쿼리의 값을 참조하며 도는 서브쿼리를 상관(Correlated) 서브쿼리라고 합니다.
Q23. 두 쿼리의 결과를 합칠 때, 중복된 데이터를 제거하고 결과를 정렬(Sort)하여 반환하는 집합 연산자는?
  • ① UNION
  • ② UNION ALL
  • ③ INTERSECT
  • ④ MINUS
해설
UNION은 중복 제거를 위해 내부적으로 정렬을 수행합니다. UNION ALL은 정렬 및 중복 제거 없이 두 결과를 그대로 합치므로 성능상 훨씬 빠릅니다.
Q24. 집합 연산자(Set Operator)를 사용하기 위한 전제 조건으로 틀린 것은?
  • ① 두 SELECT 문의 컬럼 개수가 동일해야 한다.
  • ② 대응되는 컬럼의 데이터 타입이 상호 호환 가능해야 한다.
  • ③ 두 SELECT 문의 컬럼 이름(Alias)이 완벽히 동일해야 한다.
  • ④ 최종 결과의 컬럼명은 첫 번째 SELECT 문의 컬럼명을 따른다.
해설
집합 연산자 사용 시 컬럼의 개수와 데이터 타입(순서)만 맞으면 되며, 컬럼명(이름)은 달라도 무방합니다. 결과는 첫 번째 쿼리의 컬럼명을 따라갑니다.
Q25. 첫 번째 쿼리 결과에는 존재하지만 두 번째 쿼리 결과에는 존재하지 않는 데이터를 추출하는 차집합 연산자는? (Oracle 기준)
  • ① INTERSECT
  • ② EXCEPT
  • ③ MINUS
  • ④ NOT IN
해설
차집합을 구할 때 오라클은 MINUS를, SQL Server 등은 EXCEPT를 사용합니다.
Q26. 동점자가 있을 경우 동일한 순위를 부여하고, 그 다음 순위는 건너뛰지 않고 이어서 부여하는(예: 1등, 2등, 2등, 3등) 함수는?
  • ① RANK()
  • ② ROW_NUMBER()
  • ③ DENSE_RANK()
  • ④ NTILE()
해설
RANK는 1, 2, 2, 4 등수를 부여합니다. 촘촘하게 순위를 매기는 DENSE_RANK는 1, 2, 2, 3 등수를 부여합니다. ROW_NUMBER는 무조건 고유한 번호(1, 2, 3, 4)를 매깁니다.
Q27. 윈도우 함수 내에서 데이터들을 특정 기준 컬럼으로 소그룹화(분할)하기 위해 사용하는 구문은?
  • ① GROUP BY
  • ② ORDER BY
  • ③ PARTITION BY
  • ④ DIVIDE BY
해설
윈도우 함수 안에서는 GROUP BY 대신 PARTITION BY 절을 사용하여 소그룹으로 나눕니다. (예: 부서별 급여 순위 산정)
Q28. 현재 읽고 있는 행을 기준으로 파티션 내에서 '이전 행'의 값을 가져올 수 있는 함수는?
  • ① LEAD()
  • ② LAG()
  • ③ PREV()
  • ④ FIRST_VALUE()
해설
이전 행의 값을 가져오는 함수는 LAG(), 다음(이후) 행의 값을 가져오는 함수는 LEAD() 입니다.
Q29. 계층형 질의에서 트리(Tree) 전개의 시작 위치(루트 데이터)를 지정하는 구문은?
  • ① CONNECT BY
  • ② PRIOR
  • ③ START WITH
  • ④ ORDER SIBLINGS BY
해설
최상위 부모 노드(루트)를 결정하는 절은 START WITH 입니다. CONNECT BY는 부모와 자식 노드 간의 연결 조건을 명시합니다.
Q30. "CONNECT BY PRIOR 사원번호 = 관리자번호" 조건으로 전개 시 계층 전개 방향으로 올바른 것은?
  • ① 부모에서 자식으로 전개 (순방향 전개)
  • ② 자식에서 부모로 전개 (역방향 전개)
  • ③ 형제 노드끼리 전개
  • ④ 에러가 발생하여 전개되지 않음
해설
PRIOR 키워드가 있는 쪽이 '현재(부모) 읽은 행'을 의미합니다. 즉, 방금 읽은 사원의 사원번호가 다음 행의 관리자번호가 되는 구조이므로 위에서 아래로 내려가는 순방향 전개(Top-Down)입니다.
