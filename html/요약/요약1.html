📑 SQLD 1과목: 데이터 모델링의 이해

시험에 무조건 나오는 1과목 핵심 암기 포인트 단권화

1. 데이터 모델링의 특징과 3단계

  • 데이터 모델링 3대 특징 (필수 암기): 추상화(간략하게 표현), 단순화(규약에 의해 제한된 표기법 사용), 명확성(애매모호함 없이 한 가지 의미만)
  • 데이터 모델링의 3단계 진행:
    개념적 모델링 전사적 관점, 포괄적, 추상화 수준이 가장 높음, 핵심 엔터티와 관계 도출 (ERD 창출)
    논리적 모델링 가장 핵심적인 단계, 정규화 수행, 식별자 확정, M:N 관계 해소, 특정 DBMS에 종속되지 않음
    물리적 모델링 특정 DBMS의 성능, 디스크 저장 구조, 인덱스 등을 고려하여 물리적 스키마 생성
💡 데이터 독립성 (3단계 스키마 구조)
• 외부 스키마: 사용자 관점 (사용자가 보는 뷰)
• 개념 스키마: 통합 관점 (모든 사용자 뷰를 통합한 전체 논리 구조)
• 내부 스키마: 물리적 관점 (실제 데이터가 디스크에 저장되는 물리 구조)
➔ 목적: 논리적 독립성(개념 스키마가 변경되어도 외부 스키마 영향 X)과 물리적 독립성(내부 스키마가 변경되어도 개념 스키마 영향 X) 보장

2. 엔터티(Entity), 속성(Attribute), 관계(Relationship)

엔터티 (Entity) 업무에 필요하고 관리하고자 하는 정보. 유일한 식별자가 있어야 함.
반드시 2개 이상의 인스턴스와 2개 이상의 속성을 가져야 함.
• 발생 시점에 따른 분류: 기본 엔터티(사원, 부서) ➔ 중심 엔터티(계약, 주문) ➔ 행위 엔터티(주문내역, 결제)
속성 (Attribute) 업무에서 필요로 하는 더 이상 쪼갤 수 없는 최소 의미 단위. (원자성)
• 특성에 따른 분류: 기본 속성(이름, 나이) / 설계 속성(코드, 일련번호) / 파생 속성(계산된 값, 총금액)
• 도메인(Domain): 각 속성이 가질 수 있는 값의 범위 (데이터 타입, 크기 제약 등)
관계 (Relationship) 엔터티 간의 연관성.
• 관계의 3대 요소: 관계명(명사형/동사형), 관계차수(1:1, 1:M, M:N), 관계선택사양(필수/선택)

3. 식별자 (Identifier)

  • 주식별자(Primary Identifier)의 4대 특징: 유일성(모든 인스턴스를 유일하게 구분), 최소성(가장 적은 수의 속성으로 구성), 불변성(값이 변하지 않아야 함), 존재성(반드시 값이 있어야 함, NOT NULL)
  • 식별자의 분류:
    • 대표성 여부: 주식별자 (대표 O) vs 보조식별자 (대표 X, 참조 불가)
    • 생성 여부: 내부식별자 (스스로 생성) vs 외부식별자 (타 엔터티로부터 받아옴, FK)
    • 속성 수: 단일식별자 (1개) vs 복합식별자 (2개 이상)
    • 대체 여부: 본질식별자 (업무에 의해 생성) vs 인조식별자 (인위적으로 만든 일련번호)
💡 식별자 관계 vs 비식별자 관계
• 식별자 관계 (실선): 부모의 주식별자를 자식의 '주식별자(PK)'로 상속받음. (강한 연결)
• 비식별자 관계 (점선): 부모의 주식별자를 자식의 '일반 속성(FK)'으로만 상속받음. (약한 연결, 조인 감소 및 독립성 확보 유리)

4. 정규화(Normalization)와 반정규화

데이터의 이상현상(Anomaly - 삽입/수정/삭제 이상)을 제거하고 무결성을 유지하기 위해 테이블을 쪼개는 과정입니다.

제1정규화 (1NF) 모든 속성은 원자값(단일 값)을 가져야 한다. (속성의 다중값 분리)
제2정규화 (2NF) 주식별자가 복합키일 때 발생. 부분 함수 종속성을 제거하고 완전 함수 종속을 이룸.
제3정규화 (3NF) 주식별자가 아닌 일반 속성들 간의 종속 관계인 이행 함수 종속성(A➔B, B➔C)을 제거.
BCNF 결정자가 후보키가 아닌 함수 종속성을 제거. (모든 결정자가 후보키여야 함)
  • 반정규화 (Denormalization): 정규화를 거치면 테이블이 많아져 조인(Join)이 늘어나 조회 성능이 저하될 수 있습니다. 이를 극복하기 위해 시스템의 성능 향상을 목적으로 데이터 무결성을 일부 포기하고 데이터의 중복을 허용하는 설계 기법입니다. (테이블 병합, 컬럼 중복, 관계 중복 등)
