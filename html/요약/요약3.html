🚀 SQLD 2과목: SQL 기본 및 활용 (Part 2)

JOIN, 서브쿼리, 집합 연산자, 윈도우 함수, 계층형 질의 요약

1. 표준 JOIN (ANSI JOIN)

  • INNER JOIN: 교집합. 두 테이블 간에 조인 조건이 일치하는 데이터만 출력합니다.
  • LEFT OUTER JOIN: 왼쪽 테이블의 데이터는 무조건 모두 출력하며, 오른쪽 테이블에 매칭되는 값이 없으면 NULL로 채워 출력합니다.
  • CROSS JOIN: 조인 조건이 없을 때 발생하며 카티시안 곱(Cartesian Product)이라고도 합니다. (A테이블 행 수 × B테이블 행 수)만큼 데이터가 생성됩니다.
NATURAL JOIN 두 테이블 간에 이름과 데이터 타입이 같은 모든 컬럼을 찾아 자동으로 INNER JOIN 합니다.
※ ON 절 사용 불가, 식별자(Alias) 사용 불가
USING 조건절 조인하려는 컬럼명이 같을 때 ON A.ID = B.ID 대신 USING (ID)로 간략하게 사용합니다.
※ 식별자(Alias) 사용 불가

2. 서브쿼리 (Subquery)

서브쿼리가 위치한 곳에 따라 명칭과 역할이 다릅니다.

스칼라 서브쿼리 SELECT 절에 위치. 반드시 단일 행, 단일 컬럼의 결과만 반환해야 합니다.
인라인 뷰 (Inline View) FROM 절에 위치. 메인 쿼리 실행 시 동적으로 생성되는 일회성 가상 테이블입니다.
중첩 서브쿼리 WHERE, HAVING 절에 위치. 데이터를 필터링하기 위한 조건으로 사용됩니다.
💡 상관(연관) 서브쿼리 (Correlated Subquery)
메인 쿼리의 컬럼을 서브쿼리 내부로 끌고 들어와 조인 조건 등으로 사용하는 쿼리입니다. 메인 쿼리의 데이터가 한 줄 읽힐 때마다 서브쿼리가 반복해서 실행됩니다.
  • 다중행 연산자: 서브쿼리의 결과가 2건 이상 반환될 때 =, >, < 는 쓸 수 없으며, 반드시 IN, ANY, ALL, EXISTS를 사용해야 합니다.

3. 집합 연산자 (Set Operator)

두 개 이상의 SELECT 쿼리 결과를 하나로 합칩니다. 단, 컬럼의 개수와 데이터 타입이 같아야 사용 가능합니다. (컬럼명은 달라도 무방)

  • UNION: 합집합. 중복된 데이터를 제거하며, 중복 제거를 위해 내부적으로 정렬(Sort) 작업이 발생합니다.
  • UNION ALL: 중복을 포함한 단순 결합. 정렬 작업이 발생하지 않아 UNION보다 수행 속도가 빠릅니다.
  • INTERSECT: 교집합. 두 쿼리 결과에 공통으로 존재하는 데이터만 추출합니다.
  • MINUS / EXCEPT: 차집합. 첫 번째 쿼리 결과에는 있고, 두 번째 결과에는 없는 데이터를 추출합니다. (오라클은 MINUS, SQL Server는 EXCEPT 사용)

4. 윈도우 함수 (Window Function)

행과 행 간의 관계를 쉽게 정의하기 위한 함수입니다. 윈도우 함수 안에서는 GROUP BY 대신 PARTITION BY를 사용하여 소그룹으로 나눕니다.

순위 함수 • RANK: 1, 2, 2, 4 (동점자 다음 순위 건너뜀)
• DENSE_RANK: 1, 2, 2, 3 (순위를 촘촘하게 이어서 부여)
• ROW_NUMBER: 1, 2, 3, 4 (동점자여도 무조건 고유한 일련번호 부여)
행 참조 함수 • LAG: 파티션 내에서 이전 행의 값을 가져옴
• LEAD: 파티션 내에서 다음 행의 값을 가져옴

5. 계층형 질의 (Hierarchical Query)

조직도, 메뉴 트리처럼 부모-자식 관계의 데이터를 계층적으로 풀어내는 오라클 특화 쿼리입니다.

  • START WITH: 트리 전개의 시작점(루트 노드 데이터)을 지정합니다.
  • CONNECT BY: 부모와 자식 간의 연결 조건을 명시합니다.
    • CONNECT BY PRIOR 자식 = 부모 : 자식에서 부모로 올라가는 역방향 전개 (Bottom-Up)
    • CONNECT BY PRIOR 부모 = 자식 : 부모에서 자식으로 내려가는 순방향 전개 (Top-Down)
  • ORDER SIBLINGS BY: 전체 데이터가 아닌 형제 노드(동일 레벨) 사이에서만 정렬을 수행합니다.
